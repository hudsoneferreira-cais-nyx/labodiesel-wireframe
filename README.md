# Labodiesel · prévia do site

Prévia navegável do novo site da Labodiesel (HTML único, fotos embutidas), sem itens de guia, para funcionar como o site final.

- `/` — versão com fundo azul (principal), arquivo `index.html`.
- `/creme` — a mesma página com fundo creme, arquivo `creme.html`.

Observações:

- O formulário de contato ainda não envia mensagens: nesta prévia ele só mostra um aviso.
- A página está protegida contra indexação (`noindex`, `X-Robots-Tag` e `robots.txt`). Ao publicar o site de verdade, remova essas três travas.
- Para atualizar, troque `index.html` e/ou `creme.html` e faça commit: a Vercel publica sozinha.
